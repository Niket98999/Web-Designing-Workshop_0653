# Web Designing Workshop - Experiments

HTML experiments submitted for the Web Designing Workshop course.

## Experiments

| File | Topic |
|---|---|
| `exp-1.html` | Course curriculum page - headings, paragraphs, ordered, unordered, description and nested lists |
| `Experiment2.html` | News website layout - navigation links, image, embedded YouTube video, video and audio elements |
| `Experiment3.html` | Class time-table using tables - rowspan, colspan, nested table and caption |

## How to view

Open any `.html` file in a browser, or enable GitHub Pages.
